# thesis-format-cn —— 中文论文格式 SKILL

## 它解决什么

把中文论文里最容易出错、又最费时的几件事一次做对：

- 标题层级用**多级列表**自动编号（一、/（一）/ 1.），不是手写
- 图/表题注用 **SEQ 域**自动生成「图1」「表1」，正文用 **REF 域**交叉引用
- 参考文献**自动编号**，正文引用是右上标 `[1][2]` 且同样用交叉引用
- 柱状图/饼图/折线图等用 **Word 原生图表**（可双击进 Excel 改数据），不用 Python 画图
- 中文双引号强制用中文字体（正文宋体，摘要与参考文献楷体），西文一律 Times New Roman
- 标准三线表；表跨页自动重复表头、不断行；图片与图表自动缩放到版心内


## 排版速查

| 项 | 规定 |
|---|---|
| 页面 | A4，上下 2.54 cm，左右 3.17 cm，页脚居中页码 |
| 正文 | 宋体五号，1.5 倍行距，首行缩进 2 字符 |
| 大标题 | 黑体三号居中；副标题 宋体小四居中 |
| 摘要 / 关键词 | 标签黑体五号，**内容楷体五号** |
| 标题 1/2/3 | 黑体小四 / 宋体五号 / 宋体五号 |
| 参考文献 | 标题 黑体小四；条目 楷体五号（西文也用楷体） |
| 西文 | Times New Roman（参考文献除外） |
| 图表 | 原生图表，宽 ≤ 12 cm、高 ≤ 7 cm |
| 图片 | 等比缩放，宽 ≤ 14 cm、高 ≤ 8 cm |
