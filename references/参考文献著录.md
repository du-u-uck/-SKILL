# 参考文献著录规则

《实践教学论文格式范文》给出的著录格式（GB/T 7714 体例），分类小标题加粗，
条目用楷体五号、左顶格，序号形式为 `[1]`、`[2]`……

## 通用格式

```
[序号]主要责任者．文献题名[文献类型标识]．出版地：出版者，出版年．
```

- 序号用**半角方括号**：`[1]`
- 分隔符用**全角句点** `．`（不是英文小数点 `.`）
- 责任者之间用 `，`；三个以上责任者用 `，` 分隔（范文示例即如此）
- 年份后用 `．` 结尾

## 五类文献

### （1）学术著作、论文集、学位论文、报告

```
[序号]主要责任者．文献题名[文献类型标识]．出版地：出版者，出版年．
例：[1]刘国，陈绍业，王风翥．图书馆目录[M]．北京：高等教育出版社，1957．
    [2]辛希孟．信息技术与信息服务国际研讨会论文集：A集[C]．北京：中国社会科学出版社，1994．
（学位论文题名[D]、报告题名[R]，此处不一一列举）
```

文献类型标识：`[M]` 专著、`[C]` 论文集、`[D]` 学位论文、`[R]` 报告。

### （2）期刊文章

```
[序号]主要责任者．文献题名[J]．刊名，出版年，卷号（期号）．
例：[3]成升魁，沈镭．青藏高原人口、资源、环境与发展互动关系探讨[J]．自然资源学报，2000，15（4）．
```

### （3）论文集中的析出文献

```
[序号]析出文献主要责任者．析出文献题名[A]．原文献主要责任者．原文献题名[C]．出版地：出版者，出版年．
例：[4]钟文发．非线性规划在可燃毒物配置中的应用[A]．赵玮．运筹学的理论与应用——中国运筹学会第五届大会论文集[C]．西安：西安电子科技大学出版社，1996．
```

### （4）报纸文献

```
[序号]主要责任者．文献题名[N]．报纸名，出版日期（版次）．
例：[5]谢希德．创造学习的新思路[N]．人民日报，1998-12-25（10）．
```

### （5）电子文献

```
[序号]主要责任者．电子文献题名[EB/OL]．电子文献的出处或可获得地址，发表或更新日期/引用日期（任选）．
例：[6]王明亮．关于中国学术期刊标准化数据库系统工程的进展[EB/OL]．http://www.cajcd.edu.cn/pub/wml.txt/980810-2.html,1998-08-16/1998-10-04．
```

## 在文档中的落地方式

- 分类小标题（（1）学术著作…）用 `PaperRefCategory`（楷体加粗）；
- 条目用 `PaperRefItem`（楷体，西文也用楷体，左顶格，无悬挂缩进）；
- 序号由**自动编号列表**生成（`numId=91`，`lvlText="[%1]"`），不手写；
  增删条目后序号自动重排，正文 `{ REF _Ref_RefN \r \h }` 交叉引用同步更新；
- 如果参考文献来自手写草稿（形如 `[1] 刘国，……`），
  `python scripts/paper_format.py format 草稿.docx` 会把手写序号转成自动编号并补齐书签。

## 注意事项

- 英文书名/刊名用斜体（如需），不要用下划线。
- 中文文献的出版地、出版者之间用全角冒号 `：`。
- URL 之后不加句点（范文示例里加了一个 `．`，可按投稿要求统一去掉）。
- 英文期刊的期号用半角括号 `(4)`，中文期刊用全角括号 `（4）`——范文中文条目用全角。
