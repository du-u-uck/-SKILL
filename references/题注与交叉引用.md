# 题注、交叉引用、三线表与分节符的实现

## 1. 题注（SEQ 域）

题注段落结构（`Caption` 样式）：

```
<w:p>
  <w:pPr><w:pStyle w:val="Caption"/><w:autoSpaceDE w:val="0"/><w:autoSpaceDN w:val="0"/></w:pPr>
  <w:bookmarkStart w:name="_Ref_Figure_1"/>          ← 覆盖「标签+序号」
  <w:r><w:t>图</w:t></w:r>
  <w:bookmarkStart w:name="_Ref_Figure_1_num"/>      ← 仅覆盖序号
  ... { SEQ Figure \* ARABIC } ...
  <w:bookmarkEnd/>
  <w:bookmarkEnd/>
  <w:r><w:t xml:space="preserve"> 图名</w:t></w:r>
</w:p>
```

- 序号用 `SEQ Figure` / `SEQ Table`（标识符用 ASCII，避免不同语言版本 Word 的兼容问题），
  标签文字「图」「表」直接写在域前面。
- 序号由域自动生成，插入/删除图表后按 `Ctrl+A` → `F9` 即可整体更新。
- 每份文档保留两个书签：`_Ref_Figure_N`（标签+序号）与 `_Ref_Figure_N_num`（仅序号），
  表格同理为 `_Ref_Table_N` / `_Ref_Table_N_num`。

## 2. 文中交叉引用（REF 域）

| 想要的显示 | 书签 | 前缀 |
|---|---|---|
| 见图1 | `_Ref_Figure_1_num` | `见图` |
| 见图1 | `_Ref_Figure_1` | `见` |
| 见表1 | `_Ref_Table_1_num` | `见表` |
| 见表1 | `_Ref_Table_1` | `见` |

域代码：`{ REF _Ref_Figure_1_num \h }`，`\h` 表示结果为超链接（可 Ctrl+单击跳转）。

`paperlib.add_crossref(paragraph, bookmark, prefix=..., suffix=...)` 即生成该结构。

## 3. 原生图表的实现（chartlib）

`chartlib.build_chart_xml()` 生成 `c:chartSpace`，要点：

- 图表类型对应元素：`barChart`（柱状图 `barDir=col` / 条形图 `barDir=bar`）、
  `pieChart`、`lineChart`、`areaChart`、`doughnutChart`、`scatterChart`。
- 元素顺序必须符合 schema，例如 `c:barChart` 依次是
  `barDir → grouping → varyColors → ser* → gapWidth → overlap → axId → axId`；
  `c:ser` 依次是 `idx → order → tx → invertIfNegative/marker → dLbls → cat → val → smooth`。
  顺序错了 Word 会报"文档损坏"。
- 坐标轴 id 成对出现（`catAx` 与 `valAx` 的 `axId` 交叉引用），饼图/环形图不要坐标轴。
- 数据既写入 `c:strCache`/`c:numCache`（缓存，Word 直接显示），
  也写入 `c:f` 公式引用（指向内嵌工作簿的 `Sheet1!$B$2:$B$5`）。
- 内嵌工作簿用 openpyxl 生成：A 列放类别，B 列起每列一个系列，第 1 行是系列名。
- 图表部件末尾必须挂 `<c:externalData r:id="rId1">` 指向内嵌工作簿，
  并在 `chartN.xml.rels` 里声明 `.../relationships/package` 关系。
- 字体走 `c:txPr`：西文 Times New Roman、中文宋体；图表标题用黑体。

排版约束：

- 图表段落居中，带 `keepNext`，与图题同页。
- 宽 ≤ 12 cm、高 ≤ 7 cm（上限 14 cm × 8 cm），不能占满整页。
- 图表与图片共用「图N」编号（同一套 `SEQ Figure` 域）。

## 4. 参考文献上标引用（REF \r）

参考文献条目使用独立的自动编号列表（`numId=91`，`lvlText="[%1]"`），每条在**段首**放一个空书签
`_Ref_RefN`。正文引用写：

```
{ REF _Ref_Ref1 \r \h }
```

- `\r` = 取所引用段落的编号（即 `[1]` 中的 1，含方括号由列表格式决定）。
- `\h` = 超级链接。

**关键实测结论**：必须用 `\r`。

| 写法 | Word 更新域后 | 上标是否保留 |
|---|---|---|
| `{ REF _Ref_RefN \r \h }` | 结果为 `[1]`，格式取自域自身 | ✅ 保留 |
| `{ REF _Ref_RefN \h }`（取书签正文） | 结果为书签内文字，格式取自参考文献条目 | ❌ 上标被覆盖 |

原因是 `REF` 取书签正文时，Word 会连同源文本的字符格式一起复制过来，把上标冲掉。
用 `\r` 取"段落编号"时，Word 自己生成编号文本，域上的格式得以保留。

连续引用 `[1][2]` 就是并排放两个域：`{REF _Ref_Ref1 \r \h}{REF _Ref_Ref2 \r \h}`，
两者都套 `PaperCite` 字符样式（或直接 `vertAlign=superscript`）。

引用序号放在**相关句子末尾**，右上标，即插在句末句号之前或之后（全文统一）。

## 5. 三线表

```xml
<w:tblBorders>
  <w:top    w:val="single" w:sz="12"/>   <!-- 1.5 pt -->
  <w:left   w:val="none"/>
  <w:bottom w:val="single" w:sz="12"/>   <!-- 1.5 pt -->
  <w:right  w:val="none"/>
  <w:insideH w:val="none"/>
  <w:insideV w:val="none"/>
</w:tblBorders>
```

表头行另外加单元格下边框：

```xml
<w:tcBorders><w:bottom w:val="single" w:sz="6"/></w:tcBorders>  <!-- 0.75 pt -->
```

表头行 `w:trPr` 加 `<w:tblHeader w:val="true"/>` 使其跨页重复。

注意 `w:tcBorders` 在 `w:tcPr` 中的位置要排在 `w:tcW` 之后、`w:shd` 之前；
`w:tblBorders` 在 `w:tblPr` 中要排在 `w:tblLayout`/`w:tblCellMar` 之前，否则 Word 会报文档损坏。

## 6. 分节符

Word 把分节符保存在**上一节最后一段**的 `w:pPr/w:sectPr` 中。给参考文献/附录另起一页的做法：

1. 取正文末尾（目标标题的前一个段落）的 `w:pPr`；
2. 把文档级 `w:sectPr` 复制一份，设为 `<w:type w:val="nextPage"/>`；
3. 挂到该段的 `w:pPr` 末尾（`sectPr` 是 `pPr` 的最后一个子元素）。

`paperlib.insert_section_break_before(doc, paragraph)` 实现了这套逻辑。
不要用普通分页符代替：分节符才能让后续页眉页脚、页码编号独立。

**往「参考文献」标题之前插内容时**，要插到承载分节符的那一段**之前**
（`preceding_section_break_paragraph()`），否则新内容会落进下一节，
与参考文献标题挤在同一页。

## 7. 引号处理

全角引号 “ ” 属"歧义宽度"字符（East Asian Ambiguous）。Word 在 `w:hint="default"` 时
按西文字体渲染它们——得到高位置、瘦长的西式引号。要得到中文引号，必须让该字符走
`w:eastAsia` 字体：

```python
rf.set(qn('w:ascii'),   '楷体')   # 兜底
rf.set(qn('w:hAnsi'),   '楷体')
rf.set(qn('w:eastAsia'),'楷体')
rf.set(qn('w:hint'),    'eastAsia')   # 关键
```

`paperlib.fix_quotes()` 的做法：

1. 遍历 body / 页眉 / 页脚里的每个段落；
2. 按段落样式判定引号字体：`PaperAbstract`/`PaperKeywords`/`PaperAbstractEN` → 楷体，
   `PaperRefItem`/`PaperRefCategory` → 楷体，其余沿用该 run 原有中文字体（默认宋体）；
3. 把含引号的 run 按引号位置**切分**成多个 run，引号单独成 run 并写入上述 `rFonts`；
4. 跳过域代码 run（含 `fldChar`/`instrText`），避免破坏 SEQ/REF 域。

之所以必须"切分"而不是整段改字体：摘要正文是黑体，但摘要里的引号要用楷体，
只有把引号单独切出来才能单独指定字体。
