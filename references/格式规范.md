# 论文格式规范（完整参数表）

来源与取舍：

- **《实践教学论文格式范文.doc》** —— 主参考。字号、字体、缩进、行距、参考文献著录格式均以此为准。
- **《论文格式模板.docx》** —— 提供标题样式与多级列表的骨架（`标题1` 绑定 `chineseCountingThousand` + `、`；
  `标题2` 绑定 `（%2）`；`Normal` 行距 360 auto = 1.5 倍）。
- **《设计说明书.docx》** —— 多级列表层级划分参照（1. / 1.1 / 1.1.1）。

冲突项的处理：大标题字号两份模板不一致（范文为四号，格式模板为三号），
本规范取 **三号**（`论文格式模板`），范文为四号时可在 `paperlib.SIZE_4HAO` 处改。

## 1. 页面设置

| 项 | 值 | 备注 |
|---|---|---|
| 纸张 | A4（21.0 × 29.7 cm） | 三份模板一致 |
| 上/下边距 | 2.54 cm | |
| 左/右边距 | 3.17 cm | |
| 页眉距边界 | 1.5 cm | |
| 页脚距边界 | 1.75 cm | |
| 页码 | 页脚居中，`PAGE` 域 | 范文为居中 PAGE |
| 中文/西文自动间距 | 关闭（`autoSpaceDE=0` / `autoSpaceDN=0`） | 使「图1」「表1」紧凑显示 |

文档默认值（`docDefaults`）：西文 `Times New Roman`，中文 `宋体`，字号 五号(21 半磅)，
行距 360 auto（1.5 倍），两端对齐，段前段后 0。

## 3. 多级列表（标题编号）

一套多级列表（`abstractNumId=90` / `numId=90`）绑定 `标题1/2/3`：

| 层级 | 绑定样式 | 编号格式 | 编号文本 | 缩进 |
|---|---|---|---|---|
| 1 | Heading 1 | `chineseCountingThousand` | `%1、` → 一、二、三 | 首行 2 字符（小四 480 twips） |
| 2 | Heading 2 | `chineseCountingThousand` | `（%2）` → （一）（二） | 首行 2 字符（五号 420 twips） |
| 3 | Heading 3 | `decimal` | `%3.` → 1. 2. 3. | 首行 2 字符（五号 420 twips） |

- `w:suff="nothing"`：编号后不插入制表符/空格，标题文字紧跟编号，与范文一致。
- 编号与标题都带 2 字符首行缩进，与范文一致。
- 参考文献使用**另一套**独立列表（`numId=91`，`lvlText="[%1]"`），不参与标题编号。
- 附录内的小节标题用 `PaperAppendixHeading`，**不挂多级列表**，否则会被编成「三、附录 A …」。

## 4. 字体与引号

- 所有中文样式只设置 `w:eastAsia`；`w:ascii`/`w:hAnsi` 一律 `Times New Roman`。
  唯一例外是 `PaperRefItem` / `PaperRefCategory`（西文也用楷体）。
- 每个 run 的 `w:rFonts` 带 `w:hint="eastAsia"`，使中文标点与全角引号取中文字体。
- 中文双引号（全角 “ ”）必须使用中文字体：
  - 摘要、关键词、参考文献区 → **楷体**
  - 正文、标题 → 该 run 原有中文字体（默认宋体）
- 实现方式见 [题注与交叉引用.md](题注与交叉引用.md) 的「引号处理」一节。

## 5. 图片与图表

### 5.1 图表必须用 Word 原生图表

柱状图、条形图、饼图、折线图、面积图、环形图、散点图一律使用 Word 自带的「插入 → 图表」，
**不得用 Python（matplotlib 等）画成图片再插入**。

生成的文档应包含以下部件，缺一不可：

| 部件 | 路径 | 作用 |
|---|---|---|
| 图表部件 | `/word/charts/chartN.xml` | DrawingML 图表定义（`c:chartSpace`） |
| 数据工作簿 | `/word/embeddings/Microsoft_Excel_WorksheetN.xlsx` | 图表的「编辑数据」源 |
| 关系 | `word/charts/_rels/chartN.xml.rels` | 图表 → 工作簿（`.../relationships/package`） |
| 关系 | `word/_rels/document.xml.rels` | 文档 → 图表（`.../relationships/chart`） |
| 内容类型 | `[Content_Types].xml` | 图表部件用 Override，`.xlsx` 用 Default |

正文里是 `<w:drawing><wp:inline>…<c:chart r:id="rIdN"/></wp:inline></w:drawing>`。

这样做的收益：双击图表可进入 Excel 编辑数据、跟随 Word 主题换配色、可直接改类型与样式。
用 matplotlib 画出来的 PNG 做不到这些，且字体与全文不一致。

### 5.2 尺寸与版心

版心（去掉页边距后的可排版区域）：宽 **14.66 cm**，高 **24.62 cm**。

| 对象 | 宽度上限 | 高度上限 | 说明 |
|---|---|---|---|
| 图片 | 14.0 cm | 8.0 cm | 等比缩放，超大原图自动缩小 |
| 图表 | 12.0 cm（默认） | 7.0 cm（默认） | 可调，但同样不得超过上述上限 |

- 一律**等比缩放**，不得拉伸变形；原始尺寸小于上限时保持原尺寸，不放大。
- 图片、图表段落**居中**。
- 图片段落设 `keepNext`，图与图题不被分到两页。
- 图片/图表高度上限取版心的约三分之一，保证一屏能放下图与周围正文。

## 6. 表格

标准三线表：

| 线 | 位置 | 线宽 |
|---|---|---|
| 顶线 | 表格上边框 | 1.5 pt（`w:sz=12`） |
| 表头下线 | 表头行单元格下边框 | 0.75 pt（`w:sz=6`） |
| 底线 | 表格下边框 | 1.5 pt（`w:sz=12`） |
| 竖线 / 内部横线 | — | 全部 `none` |

- 表头行设 `w:tblHeader`，跨页时自动重复。
- 表内文字用 `PaperTableText`（宋体五号居中）。
- 表题在表格**上方**，图题在图片**下方**，均为黑体五号居中。

## 7. 表格跨页处理

表格跨页时必须同时做好三件事：

| 措施 | OOXML | 效果 |
|---|---|---|
| 表头行跨页重复 | 表头行 `w:trPr` 加 `<w:tblHeader w:val="true"/>` | 续页顶部自动重复表头 |
| 单行不跨页断开 | 每行 `w:trPr` 加 `<w:cantSplit/>` | 不会出现"半行"被劈开 |
| 表题与表格同页 | 表题段落 `w:keepNext` | 表题不会被单独留在页尾 |

补充规则：

- 图题在图**下方**且图段落带 `keepNext`；表题在表**上方**且表题段落带 `keepNext`。
- 估算表格高度超过版心 **55%** 时，自动把表内字号降到小五（9pt）、行距改为单倍，
  让表格不至于占满大半页。
- 表格宽度不得超过版心宽 14.66 cm。

## 8. 分节分页

- 参考文献：正文末尾插入 `nextPage` 分节符，参考文献标题另起一页。
- 附录：同样处理，附录另起一页。
- 两处都不得用普通分页符（`w:br type="page"`）替代——分节符才能让页码、页眉页脚独立可控。

## 9. 关键词与摘要的细节

- **摘要**：标签写作 `摘  要：`（中间两个空格，范文原样），用**黑体**五号；
  标签之后的摘要正文用**楷体**五号。两者在同一个段落里，靠字符样式 `PaperLabel` 区分。
- **关键词**：标签 `关键词：` 用**黑体**五号；关键词内容用**楷体**五号；
  关键词之间空 **2 个空格**（范文原样）。
- 实现方式：`mark_leading_label(paragraph)` 把段首的标签切成独立 run 并套 `PaperLabel` 字符样式，
  段落样式本身只负责楷体五号。样式控制字号字体，因此不要给标签加直接格式。
- 摘要与正文之间空两行（两个空段落）。
- 摘要中的中文双引号随正文一并为楷体（`fix_quotes` 对 `PaperAbstract`/`PaperKeywords` 强制楷体）。
